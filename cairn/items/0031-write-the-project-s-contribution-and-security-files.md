## Problem

No CONTRIBUTING, CHANGELOG, or SECURITY policy. A contributor cannot tell how to
propose a change, and someone finding a vulnerability has nowhere to send it.

## Proposal

CONTRIBUTING.md pointing at `cairn next` for what needs doing — the project
tracks itself, so the backlog is the contribution guide. CHANGELOG.md in
keep-a-changelog form. SECURITY.md with a contact and a disclosure window.

## Acceptance criteria

- [ ] A newcomer can find something to work on without asking
- [ ] Changelog updated as part of the release process, not after
- [ ] Security contact reachable and monitored
