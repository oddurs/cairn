# Format 1

Item files as format 1 wrote them, with the values they must still parse to.

**Frozen.** Format 1 stopped being current when format 2 arrived, and nothing
here changes again. If a case is wrong, it was wrong then — and what a reader
meets in ten years is what was actually written, not what we wish had been.

The corpus for the current format lives one directory up. These exist so that a
cairn built next year can be shown to still read a file written this year, which
is the promise the format number makes on the project's behalf and the only
test that can fail for the right reason years from now.
